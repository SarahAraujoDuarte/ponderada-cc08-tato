# Ponderada Computação CC08 — do pipeline ao deadlock

**Autora:** Sarah Araujo Duarte

Análise de arquitetura, memória, pipeline, concorrência e deadlock aplicada a uma pulseira sensorial de auxílio a pessoas com deficiência visual.

## Como executar a questão A4

Requisito: Python 3.10 ou superior. Nenhuma biblioteca externa é necessária.

Na raiz do repositório, execute cada versão com um único comando:

```bash
python3 ponderada/codigo/versao1.py
python3 ponderada/codigo/versao2.py
python3 ponderada/codigo/versao3.py
```

Cada comando usa as 20.000 amostras exigidas. Para um teste rápido, pode-se informar outra quantidade, por exemplo:

```bash
python3 ponderada/codigo/versao2.py --amostras 100
```

O relatório completo está em [`ponderada/ponderada-tato.md`](ponderada/ponderada-tato.md).
